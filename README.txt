Vinculum WMS Dashboard - GitHub Pages

Upload these files to a GitHub repository under your own GitHub account.
For GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.

Your site will be:
https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/

The dashboard reads Vinculum .xlsx/.xls/.csv files locally in the browser.
No Excel data is uploaded to GitHub by the dashboard.
